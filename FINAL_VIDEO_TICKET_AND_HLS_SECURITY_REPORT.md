## 1. Overview of the Video Ticket Architecture

Video streaming in OX-DIGITAL Education is protected by short-lived cryptographic tickets generated by `videoToken.service.ts` using JWT with SHA-256 HMAC encryption (`HS256`).

A video ticket contains:
- `userId`: Identifier of the authenticated viewer.
- `lessonId`: Precise lesson for which playback is authorized.
- `purpose`: Strictly bound to `'video-stream'`.
- `exp`: Short expiration lifetime (default 3600 seconds / 1 hour).
- `iat`: Timestamp of issuance.

## 2. Hardened Perimeter Defenses Implemented

### 2.1 Route & Purpose Confinement
In `services/course-service/src/middlewares/auth.middleware.ts`, `verifyToken` inspects the decoded token purpose:
- If `decoded.purpose === 'video-stream'`, the middleware inspects `req.originalUrl`.
- If the request is made to any route other than `/lessons/:id/stream` or `/lessons/:id/hls`, the request is terminated immediately with **HTTP 403 Forbidden** (`VIDEO_TOKEN_LIMITED_TO_STREAMING`).
- This prevents attackers from using video streaming tokens to manipulate courses, access grades, or alter accounts.

### 2.2 Lesson ID Scope Matching
Even on streaming routes, the token cannot be used interchangeably across lessons:
- `auth.middleware.ts` extracts `targetLessonId = req.params.id`.
- If `decoded.lessonId !== targetLessonId`, access is terminated immediately with **HTTP 403 Forbidden** (`VIDEO_TOKEN_LESSON_MISMATCH`).
- This guarantees strict 1-to-1 binding between the ticket and the requested media asset.

### 2.3 Signature Tampering & Expiration Guards
In `services/course-service/src/controllers/course.controller.ts` (`streamLessonVideo`, `streamLessonHls`):
- Tokens with forged, modified, or invalid HMAC signatures trigger `jwt.verify` exceptions and fail closed with **HTTP 401 Unauthorized** (`INVALID_STREAMING_TOKEN`).
- Expired tokens fail closed with **HTTP 401 Unauthorized** (`STREAMING_TOKEN_EXPIRED`).

### 2.4 Financial Access Control Perimeter
When generating a video ticket in `course.controller.ts` (`getLessonVideoTicket`):
- `checkUserEnrollment(userId, lesson.courseId)` performs an authoritative query on `user.financialAccessStatus`.
- If the student is marked `RESTRICTED` due to unfulfilled center tuition fees after the configured grace period, ticket issuance is rejected with **HTTP 403 Forbidden** (`FINANCIAL_RESTRICTION_ACTIVE`).
