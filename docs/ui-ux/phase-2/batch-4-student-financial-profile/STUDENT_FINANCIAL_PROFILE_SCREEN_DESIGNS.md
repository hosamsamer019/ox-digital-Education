## 1. Global Profile Header & Structural Overview

The Student Financial Profile is an integrated sub-ledger view embedded within the accepted Batch 1 App Shell. The profile canvas consists of:
1. **Student Context & Dual Status Bar:** Identity, campus branch, and distinct Academic vs Financial status badges.
2. **Financial KPI Metric Bar:** Seven mathematically isolated metric cards.
3. **Primary Tab Navigation:** Eight operational sub-views.
4. **Active Workspace Viewport:** Context-specific ledger tables, action bars, and audit drawers.
